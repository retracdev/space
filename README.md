# retrac.space
A little space for all the cool things I've built.

The experimental homepage lives at `/home-v2/` (static entry point:
`home-v2/index.html`). It explores a CSS 3D orbital scene, an interactive
extruded wordmark, and project panels using the existing videos and links.
The original homepage is unchanged. Click a logo letter to send the title
tumbling, or enter the Konami code (↑ ↑ ↓ ↓ ← → ← → B A) for a secret orbit.
Animations follow the system reduced-motion preference; video previews play
only on hover or keyboard focus. The existing `?reduce_motion=true` override
also works here. There is no motion toggle.

Run the non-browser checks with `node --test tests/*.test.cjs`.
